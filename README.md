# Georgia family trip · 24–31 October 2026

Статический семейный мини-сайт с календарём, двумя сценариями поездки и интерактивной картой.

## Локальный просмотр

Откройте папку проекта в терминале и запустите:

```bash
python3 -m http.server 4173
```

Затем откройте `http://localhost:4173`.

## GitHub Pages

Файлы можно положить в корень отдельного репозитория и включить GitHub Pages для ветки `main`, папка `/ (root)`.

## Где редактировать маршрут

- `app.js` — дни, точки карты, варианты маршрута и отелей.
- `styles.css` — оформление.
- `assets/georgia-hero.png` — обложка.

Не добавляйте в публичный репозиторий номера подтверждений, PIN-коды бронирований, паспортные данные и телефоны.
